# 新加坡留学准备清单

面向中国赴新加坡留学生的手机端静态清单，覆盖出发前办理、随身文件、行李打包、落地购买和入境安全提醒。

## 使用方式

直接打开 index.html，或通过 GitHub Pages 访问。首次打开显示 63 项默认清单，并且所有分类保持折叠。住宿与清洁、学习文具、厨房与做饭、美妆与个人护理、扩展衣物与鞋包、数码扩展、药品与健康、旅行用品共 8 个可选包，可按需启用。

页面采用单层分类。条目只显示名称，以及有内容时才显示的数量和备注；自定义条目统一进入“自定义”分类。

所有勾选、新增、编辑、删除和可选包设置只保存在当前网址、当前浏览器的 localStorage。项目不提供账号、云同步、备份导入导出或整表重置。

## 本地检查

需要 Node.js 18 或更高版本：

    node .\scripts\validate.mjs
    python -m http.server 8765

然后访问 http://127.0.0.1:8765/。

## GitHub Pages 发布

1. 创建公开 GitHub 仓库并推送 main 分支。
2. 在仓库 Settings > Pages 中选择 Deploy from a branch。
3. 选择 main 和 /(root)，保存后等待 Pages 地址生成。
4. 在 Pages 设置中启用 Enforce HTTPS。
5. 用实际地址在小红书内置浏览器、iOS Safari 和 Android Chrome 中复测。

公开仓库中的全部代码对所有人可见，不要提交账号、密钥、个人资料或浏览器存储数据。

## 内容边界

本清单综合多位 NTU、NUS 留学生在小红书分享的经验整理，不代表学校或新加坡政府官方意见。不同学校、项目、住宿和航空公司要求可能不同，请以 ICA、校方和航空公司最新通知为准。

政策性条目链接到 ICA、HSA、CAAS、Singapore Customs 和 SFA 官方资料。内容版本及最后核验日期显示在网页“说明”中，建议每个招生季开始前重新核验。

## 数据与隐私

网页不会上传清单内容，也不包含分析、广告或第三方脚本。GitHub Pages 可能为安全目的记录访问者 IP。完整说明见 [PRIVACY.md](PRIVACY.md)。

## 反馈

发布到 GitHub Pages 后，网页会根据 Pages 地址自动生成仓库 Issue 链接。内容错误、过期政策和兼容性问题可通过仓库 Issues 提交。
